# Tawfeeqoh / iamtaw

My personal homepage. A small, fast introduction to who I am, what I build and where to find my work.

**Live:** https://tawfeeqoh.name.ng/

## Built with

HTML, CSS and JavaScript. No framework or build step. The page works without JavaScript, uses locally hosted fonts and respects reduced-motion preferences.

## Run locally

```sh
python3 -m http.server 8080 --directory dist
```

Open http://localhost:8080. Deploy `dist/` as the static site; `vercel.json` contains the hosting configuration.

## In this repo

- `dist/` — the website source and assets, including favicons, sitemap and robots.txt
- `vercel.json` — deployment configuration

The portfolio and THE MARGIN are separate sites, linked from this homepage.
